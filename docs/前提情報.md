## 株式まわりの経緯

- 過去に C が株式を取得することを検討したが、すでに会社資産が大きく断念。
  - 譲渡（売買）でも C の購入額が高すぎる
  - 贈与でも贈与税が高すぎる
- → 株価が高く、かつ年5億ペースで上がり続けるため、**株式の移転で C に資産を渡すルートは実質的に塞がっている**（待つほど不利）。

## 論点メモ

- **C の処遇**: 実質経営を担うが肩書は平社員・持株 0%。役員退職金の検討対象に C を含めるなら、まず役員就任（登記）が前提になり得る。この点は今後の方針に関わるため要相談。
- **B の扱い**: すでに役員退職済み。退職金を未払なら過去分の扱い、株式 40% の今後（買取・承継）も論点になり得る。
