# 目的2: 会社で家を買うルール（役員社宅）

## 目的

会社が役員のための住居（社宅）を購入・所有し、適切な条件で役員に貸し付ける制度を整備する。これにより、会社の利益剰余金を減らしながら役員の住居費負担を軽くする。退任時には退職金として現物支給することで、会社資産を役員個人へ合法的・節税的に移転する。

上位目的（会社の資産を合法的に・節税して個人へ移す）に沿う。

## 前提（現状）

- 対象役員: A 鮫島・C 若松 を主に想定。B 高橋 も希望時のみ可。
- 既存物件: なし。これから新たに購入する想定。
- freep の利益剰余金: 約18億円。年5億円増加見込み（目的1の前提と共通）。

## 仕組みの根拠（税法）

- 法人税法基本通達 9-2-9 〜 9-2-12（役員社宅の賃貸料相当額の計算）
- 所得税基本通達 36-40 〜 36-41

会社が役員に社宅を貸し、役員から「賃貸料相当額」を徴収すれば、市場家賃との差額が経済的利益として給与課税されない。賃貸料相当額は物件規模（小規模/中規模/大規模）により計算式が異なり、市場家賃の10〜30%程度になることが多い。

## 決定事項と理由・経緯

### 決定1: 物件は会社所有とする

**結論:** 借上げではなく、会社が物件を購入して所有する。

**理由・経緯:**

- 借上げは家賃が経費になるだけで、会社資産（利益剰余金）を減らせない。
- 会社所有なら、購入時の支出で利益剰余金を減らせる。
- 上位目的（会社資産を個人へ移す）に沿うのは会社所有。

### 決定2: 退任時は退職金として現物支給する

**結論:** 退任時、物件は退職金の一部として役員に現物支給する。

**理由・経緯:**

- 役員が買い取る方式は自己資金が必要で、節税効果も低い。
- 退職金として現物支給すれば、退職所得（控除・1/2・分離課税）で軽課税。役員の自己資金も不要。
- ただし**目的1で計算している退職金額の中に物件の時価が含まれる**ため、過大役員退職給与の上限を意識した設計が必要。
- 退職金規程に「退職金の現物支給を認める」旨を明記する。

### 決定3: 対象は A・C を主に、B も希望時のみ可

**結論:** A 鮫島・C 若松は対象。B 高橋は希望時のみ対象とする。

**理由・経緯:**

- 上位目的「3名で会社資産を分配する」に沿って、3名いずれも対象としうる。
- A・C は実質経営者として住居の必要性が明確。
- B はすでに住居がある可能性が高いが、希望時に対応できる柔軟性を残す。

### 決定4: 物件の金額上限は1物件1億円

**結論:** 1物件あたり1億円を上限とする。

**理由・経緯:**

- 過大な物件取得は税務調査での否認リスクが高まる。
- 1億円は役員社宅として一般的な上限水準。
- 必要に応じて将来見直す。

### 決定5: 賃貸料相当額は法定計算式どおり

**結論:** 法人税法基本通達 9-2-9 〜 9-2-12 の計算式どおりに徴収する。

**理由・経緯:**

- 法定計算式を下回ると差額が役員給与として課税される。
- 法定どおりに徴収すれば税務上問題なし。
- 物件規模（小規模・中規模・大規模）の区分により計算式が異なる。

### 決定6: ルール違反時の特別措置は設けない

**結論:** 私的利用の制限や違反時の罰則は設けない。

**理由・経緯:**

- 役員社宅は役員の生活拠点として使うことが前提で、私的利用の概念がそもそも当てはまりにくい。
- 必要なら将来追加。

## 想定する制度の骨子

| 項目 | 内容 |
| --- | --- |
| 物件所有 | 会社 |
| 対象役員 | A 鮫島・C 若松。B 高橋 は希望時のみ |
| 1物件の上限 | 1億円 |
| 賃貸料相当額 | 法人税法基本通達どおり |
| 在任中の負担 | 役員: 賃貸料相当額のみ。固定資産税・修繕費は会社負担 |
| 退任時の処遇 | 退職金として現物支給（時価評価） |
| 現物支給の根拠 | 退職金規程に明記 |

## 残る課題

### 1. 目的1との統合試算が必要

退職金額の中に物件の時価が含まれるため、目的1の試算（現金退職金のみ）と統合する必要がある。

例: A の退職金11.9億のうち、1億円分が物件の現物 → 残り10.9億が現金。

物件価額は購入時から退任時までに変動する可能性があり、退任時の時価評価が必要。

### 2. 物件価格の変動リスク

- 不動産価格が上昇すれば、退任時の時価が購入時を上回る → 利益剰余金の追加削減効果
- 下落すれば、退任時の時価が購入時を下回る → 売却損 / 現物支給時の評価減

### 3. 役員退職金規程との整合性

- 退職金規程に「退職金の現物支給を認める」旨を明記する必要がある。
- 目的1で作成する退職金規程と統合的に設計する。

### 4. 法人税の取り扱い

- 物件購入時: 取得価額として資産計上（経費ではない）
- 毎年: 減価償却（建物部分のみ。土地は減価償却なし）
- 修繕費・固定資産税: 経費
- 退任時の現物支給: 退職金として損金算入

「購入で利益剰余金が一気に減る」訳ではなく、毎年の減価償却で徐々に減る。土地部分は減価償却されないので、土地比率が高い物件は利益剰余金の削減効果が限定的。

2. 目的1の退職金規程と統合した規程の骨子をまとめる。
3. 目的1のシミュレーションと統合した試算を作る。
