# 目的1: 会社資産を A・B・C で分ける

## 目的

将来的に株式会社freep の会社資産を A（鮫島）・B（高橋）・C（若松）で分ける。均等に分ける必要はない。**合法的に、なるべく節税して**分ける方法を決定する。

前提となる情報は [前提情報.md](./前提情報.md) を参照。

## 前提・制約（要点）

- 会社資産は約18億円、年5億円前後で増加見込み。
- C は持株0%・現状は平社員。株価が高く、株式の譲渡・贈与で C に資産を移すルートは実質的に塞がっている（待つほど不利）。
- B は役員退職済み・40%株を保有。
- A は代表取締役・60%株・在任が長い。

## 個人へ資産を移す手段の税効率（概算・要税理士確認）

| 手段 | 所得区分 | 個人の税負担 | 会社の損金 | 受け取れる人 |
| --- | --- | --- | --- | --- |
| 役員退職金 | 退職所得 | 最も軽い（控除大・1/2課税・分離） | ○ | 役員（在任が必要） |
| 株式の売却 | 譲渡所得 | 約20%（分離） | ―（株主間/自己株） | 株主 |
| 給与・賞与 | 給与所得 | 累進 最高約55% | ○ | 全員 |
| 配当 | 配当所得 | 法人税後＋総合課税で最も重い（二重課税） | × | 株主（持株比率） |

→ 大きな金額ほど「退職金」「株式譲渡」に寄せ、配当・賞与は最小化が定石。

## 3人それぞれの想定ルート（現状の立場から）

| | 立場 | 主なルート | 早めに効く手 |
| --- | --- | --- | --- |
| A | 代表・60%・在任長 | 役員退職金（大）＋株式の出口益 | 在任年数を積む |
| B | 退職済・40%株 | 株式の処分（自己株買取 or 第三者譲渡） | 退職金枠は逸した可能性 |
| C | 平社員・0%株 | 役員就任→将来の退職金枠を作る（株式ルートが塞がっているため） | 早く役員化して在任年数を積む |

## 決めるべき論点

1. **出口イメージ**（最重要・未決定）: 会社資産を最終的にどう3人の手元へ渡すか
   - 案A: 第三者へ売却して現金化（M&A）→ 譲渡所得 約20%
   - 案B: 会社を存続させ、報酬・退職金で徐々に移す
   - 案C: 廃業・清算して残余を分配（退職金を先に最大化）
   - → これが決まると主軸の手段が決まる。
2. C を役員に就任させるか／その時期
3. B の株式40%の今後（買取・承継）と過去の退職金の有無
4. 3人の分配割合の方針（均等でなくてよい）

## 検討中のプラン（Gemini 案）の検証

出典: Google ドキュメント「役員就任および退職慰労金制度整備に関するアクションプラン」
（<https://docs.google.com/document/d/175dlroWkkol86mrml5Ic3Bb-fsRcHqbfvHifKoBKo7M/edit>）

### プランの骨子

1. C（および B）を取締役に就任させ、在任年数のカウントを開始する。
2. 役員退職慰労金規程（功績倍率方式）を制定し、公証役場で確定日付を取得する。
3. 株主（創業者2名）と事前合意書を結び、退職金支払い決議の否決リスクを塞ぐ。
4. 役員構成案: A 鮫島=代表取締役社長 / C 若松=取締役副社長 / B 高橋=取締役専務。
5. C の退職金目標は約5億円。会社を畳む数年前から最終報酬月額を計画的に引き上げる。

### 検証結果（要税理士確認。Claude は税理士ではない）

総評: **骨格は妥当**だが、**過大評価と重大な見落とし**があり、最大の税務リスク（金額の過大性）が無防備。

| プランの要素 | 評価 | コメント |
| --- | --- | --- |
| 退職金ルートが最有利 | 妥当 | 退職所得は控除・1/2・分離で最軽 |
| C を早く取締役に | 妥当 | 在任年数で控除増。役員5年超でないと1/2課税が使えない |
| 平社員の数億退職金は否認 | 妥当 | 0%・平社員のままでは利益の不当分配とみなされる |
| 功績倍率方式の規程 | 概ね妥当 | 倍率の目安は役職依存（社長3.0／副社長2.4前後）。副社長だと上限が下がる |
| 確定日付の取得 | 過大評価 | 「捏造でない」証明だけ。金額の過大性は守れない |
| 事前合意書（議決権拘束） | 過大評価 | 決議成立を保証しない。A が60%単独で普通決議可能なので縛る相手は実質 A。税務署は拘束できない |
| B の在任期間通算・再就任 | リスク高 | 8年ブランクの通算は否認されやすい。B は株式ルートの方が有利 |

### 重大な見落とし（4点）

1. **金額の過大性が無防備（最大リスク）**: 退職金は「最終報酬月額 × 在任年数 × 功績倍率」超過分が損金否認（法人税法34条）。5億を狙うと最終月額を年2億規模まで上げる必要があり、その途中の役員報酬は給与所得で最高約55%課税。確定日付・事前合意書はこの否認に無力。
2. **出口（清算 vs M&A）で A・B の手取りが激変する点が未整理**:
   - 清算: 退職金で法人税圧縮できるが、残余財産分配は「みなし配当」で総合課税（最高約50%超）。
   - M&A（株式譲渡）: A・B は譲渡所得 約20% で最軽。C は0%なので退職金で取り分を作る。
   - → A・B は M&A 有利、C は退職金有利。両者を統合する設計（例: M&A 直前に C へ退職金を払い純資産を圧縮）が肝だが、プランに統合視点がない。
3. **3人合計のシミュレーションがない**: C の5億のみ。全員分の適正額が総額18億で成立するか未検証。
4. **C の名目役員否認への備え**: 取締役会出席・経営判断の実績を残す運用が前提。

### 結論

確定日付・事前合意書は安価で害もないので実施してよいが、それで安心せず、本丸（適正額のシミュレーションと出口の統合設計）を詰める必要がある。

## 決定事項

### 出口の方針（2026-06-03 決定）

- **M&A（第三者への売却）は対象外**。会社を手放す意思は現状なし。
- **会社は存続させ、役員退職金を主軸に利益剰余金を個人へ移す**。
- **時間軸は10〜20年スパン**。退職金方式では、この期間（在任年数）を変数としてシミュレーションできるようにする。
- 最終的な清算は将来のオプションとして残るが、現時点の主たる手段ではない。

### 出口決定から導かれる戦略の骨子

- M&A 除外により、A・B も株式を譲渡所得20%で現金化する道が断たれた。配当・自己株取得・清算残余分配はいずれも重課税（みなし配当・総合課税）。
- → **役員退職金が3人全員にとって最も軽い唯一の現実的ルート**。
- 10〜20年かけて計画的に退職金を支給することで、(1) 退職所得（控除・1/2・分離）で個人へ移しつつ、(2) 会社の損金で法人税を圧縮し、(3) 利益剰余金を減らして株式に残る価値（＝将来の清算時みなし配当の対象）を圧縮していく。
- 留意: 退職金には適正額の天井（最終報酬月額 × 在任年数 × 功績倍率）がある。18億超を退職金だけで全額移せるとは限らず、移しきれない分は株式のまま残り、清算みなし配当 or 承継の対象になる。総額シミュレーションで要検証。

## 退職金シミュレーションツール

Google スプレッドシート「freep 役員退職金シミュレーション」で作成。
URL: <https://docs.google.com/spreadsheets/d/1IxxEqqJBLvmmU8eArXgANMlPCDLdlvTFxmxgMbD2tuM/edit>

金額はすべて円（全桁）表示。黄色セルが入力欄。最終判断は顧問税理士の確認が前提。

### シート構成

1. **シミュレーション**（積み上げ式）: 各人の最終報酬月額・就任年・退任年・功績倍率・功労加算率を入力 → 退職金額・税・手取り・実効税率・会社の法人税圧縮効果を算出。退任年を動かして期間をシミュレーションできる。
2. **比率から逆算**（目的1向け）: 退職金総額と分配比率（A:B:C）を入力 → 各人の配分額・必要な最終報酬月額・税・手取りを逆算。
3. **前提・税率表**: 実効法人税率・所得税速算表・退職所得控除・注意事項。

### 初期値（仮）での試算メモ

- 「比率から逆算」で総額6億・比率5:3:4・在任 A23年/B10年/C10年 の場合:
  - 配分額: A 2.5億 / B 1.5億 / C 2.0億
  - 必要月額: A 約362万 / B 約625万 / C 約833万
  - 手取り: A 約1.88億 / B 約1.14億 / C 約1.50億（実効税率 約24〜25%）

### 設計上の留意点（シミュレーションから判明）

- **必要月額と過大否認のトレードオフ**: 大きな退職金を功績倍率法で正当化するには、最終報酬月額を高くする必要がある。B・C の必要月額（625万・833万）は現状想定（約400万）より高く、(1) 引き上げ途中の報酬は給与課税で重い、(2) 実態と乖離した月額は過大役員退職給与として否認されるリスクがある。
- **期間と月額のバランスが肝**: 在任年数を延ばす（退任年を後ろへ）と必要月額が下がる。期間 × 月額 × 倍率の組み合わせで適正額に収める。
- A・B の月額・就任年はまだ仮値。実数に差し替えが必要（C の月額約400万のみ既知）。

## 次のアクション

- A・B の実際の役員報酬月額・就任年を確認し、仮値を差し替える。
- 期間（退任年）と月額の現実的な組み合わせを詰め、適正額に収まる設計を税理士と検証する。
